# Cellules Infinies - Jeu Interactif

Un jeu relaxant et satisfaisant où vous pouvez interagir avec des cellules organiques qui évoluent et se divisent de manière infinie.

## 🎮 Comment jouer

- **Cliquez** n'importe où sur l'écran pour créer une nouvelle cellule ou faire se diviser une cellule existante
- **Regardez** les cellules évoluer, changer de couleur et se déplacer de manière organique
- **Utilisez** les boutons de contrôle :
  - **Réinitialiser** : Recommencer avec de nouvelles cellules
  - **Pause** : Mettre en pause ou reprendre l'animation

## ✨ Fonctionnalités

- **Génération infinie** : Les cellules apparaissent et évoluent continuellement
- **Division interactive** : Cliquez sur les cellules pour les faire se diviser
- **Évolution des couleurs** : Les cellules changent de couleur avec l'âge
- **Mouvement organique** : Physique réaliste avec friction et mouvement naturel
- **Effets visuels** : Ombres, brillances et pulsations pour un rendu satisfaisant
- **Interface responsive** : Fonctionne sur ordinateur et mobile

## 🚀 Installation

1. Téléchargez tous les fichiers dans un dossier
2. Ouvrez le fichier `index.html` dans votre navigateur web
3. Profitez du jeu !

## 📁 Fichiers inclus

- `index.html` - Page principale du jeu
- `style.css` - Styles et animations
- `script.js` - Logique du jeu et interactions
- `README.md` - Ce fichier d'instructions

## 🎯 Objectif

Il n'y a pas d'objectif final ! Le but est simplement de se détendre et de profiter des interactions satisfaisantes avec les cellules. Regardez-les grandir, se diviser et évoluer à l'infini.

## 🔧 Compatibilité

- Fonctionne sur tous les navigateurs modernes (Chrome, Firefox, Safari, Edge)
- Compatible mobile et tablette
- Aucune installation requise

Amusez-vous bien ! 🎉
