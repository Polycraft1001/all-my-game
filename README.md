# 🎮 All My Game

Tous mes jeux web réunis sur un seul site.

## Jouer
Ouvre `index.html` dans ton navigateur, ou active **GitHub Pages** (Settings → Pages → Branch `main` / root) pour jouer en ligne.

## Jeux inclus
| Jeu | Catégorie |
|---|---|
| Forest Rally Drift 3D | Course |
| Forest Rally — Classic | Course |
| La Chasse des Paysans 3D | Action |
| Cellules Infinies | Réflexion |
| Aviator Premium | Casino (argent fictif) |
| Casino Élite | Casino (argent fictif) |
| Jeu de clic | Arcade |

## Ajouter un jeu
1. Mets le fichier `.html` (ou un dossier avec `index.html`) dans `games/`.
2. Ajoute une ligne dans le tableau `GAMES` de `index.html`.
