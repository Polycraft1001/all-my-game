NumPlay

Une appli avec une trentaine de jeux gratuits pour NumWorks, plus de gros jeux à installer séparément (N0110, N0115, N0120).

Par Mason363 · GPL v3 · GitHub officiel

🎮 NumPlay Studio (choisir ses jeux) ⬇️ Télécharger NumPlay.nwa 📂 Code source

1. Navigateur

Utilise Chrome ou Edge sur ordinateur (WebUSB obligatoire).

2. Brancher

Relie la NumWorks en USB, puis ouvre l'installateur STI2D-OS ou NumPlay Studio.

3. Suivre les étapes

Laisse-toi guider. Pour toute question, va sur le Discord discord.gg/sti2d.

⚠️ Attention

Un OS non officiel peut effacer tes données et n'est pas autorisé en mode examen. Tu fais ça à tes risques.
