STI2D-OS

Un OS alternatif pour calculatrice NumWorks qui permet d'installer un système et des jeux directement sur ta calculatrice.

Projet créé par Yamii & Derim — pas par moi. Tous droits réservés à leurs auteurs.

📦 Voir le projet sur GitHub 💬 Discord officiel

1. Télécharger

Sur la page GitHub : Code → Download ZIP, puis décompresse l'archive.

2. Ouvrir l'installateur

Ouvre Standalone-Installer/STI2D-OSv1.html avec Chrome ou Edge (WebUSB obligatoire).

3. Brancher la NumWorks

Relie la calculatrice en USB et suis les étapes de l'installateur (lis bien le LISEZMOI.md).

⚠️ Attention

Installer un OS non officiel peut effacer tes données et n'est pas autorisé en mode examen. Tu fais ça à tes risques.
